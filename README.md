# Sven

I build software that runs on your own machines: a private cloud for a home server, and desktop tools that stay local. Based in Switzerland.

## Projects

| | |
| --- | --- |
| **[Fylvo](https://github.com/svenbuild/fylvo)** | A lean, private cloud for your own server. Files, sharing, office in the browser, Google Drive and OneDrive next to your own files, and apps for Android, Windows and Linux. One container. [fylvo.svenlab.dev](https://fylvo.svenlab.dev) |
| **[Diffly](https://github.com/svenbuild/diffly)** | A local desktop diff tool for files and folders on Windows, macOS and Linux. [diffly.net](https://diffly.net) |
| **[gutter](https://github.com/svenbuild/gutter)** | A terminal text editor for Windows, written in Rust. Tabs, quick open, autosave, syntax highlighting. |

## What I work with

Go, TypeScript, Rust and Kotlin. React and Svelte for interfaces, Tauri and Electron for desktop apps, Docker for everything that runs on a server.

## What I care about

- Software that works without an account at someone else's service
- Small footprint, so it runs on modest hardware
- Interfaces that are calm and fast
- Releases you can trust: signed apps, tested updates, clear notes
